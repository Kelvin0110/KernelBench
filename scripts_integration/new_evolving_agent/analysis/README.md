# Analysis Scripts for New Evolving Agent

## Purpose

This folder contains analysis utilities for runs generated by:

- `scripts_integration/new_evolving_agent/evolve_kb_batch.py`

## Scripts

### `analyze_evolving_run.py`

Computes per-level and full-subset metrics from run artifacts in `runs_evolving/<run_name>/`.

- Reads `eval_results.json` (level-first) and/or `eval_results_level_*.json`.
- Matches each `(level, problem_id)` to baseline reference runtime using KernelBench dataset metadata.
- Computes:
  - `total_count`
  - `compiled_count`
  - `correct_count`
  - `compilation_rate`
  - `correctness_rate`
  - `geo_mean_speedup`
  - `fast_p` for thresholds `0.0, 0.5, 0.8, 1.0, 1.5, 2.0`

**Usage:**

```bash
uv run python scripts_integration/new_evolving_agent/analysis/analyze_evolving_run.py \
  --run-name memory_evolving_agent_2026_04_14_15_44 \
  --hardware SONG_CPU2_A6000x2 \
  --baseline baseline_time_torch
```

Optional direct baseline path:

```bash
uv run python scripts_integration/new_evolving_agent/analysis/analyze_evolving_run.py \
  --run-name memory_evolving_agent_2026_04_14_15_44 \
  --baseline-file results/timing/SONG_CPU2_A6000x2/baseline_time_torch.json
```

**Outputs** (per run):

- `runs_evolving/<run_name>/analysis/analysis_results.json`
- `runs_evolving/<run_name>/analysis/level_<level>_metrics.json`

`analysis_results.json` includes both per-level metrics and aggregated `full_subset` metrics.

### `aggregate_fast_p_checkpoints.py`

Aggregates fast-p checkpoint metrics for a fixed set of evolving-agent and AIDE runs into one JSON file for cross-run comparison.

- **Evolving runs:** reads `runs_evolving/<run>/visualizations/performance_stats.json` (from `Self-Evolving-Agent/visualizations/kernelbench/server/generate_run_performance_stats.py`).
- **AIDE runs:** reads `run_integration/analysis/aide_subset_run_<run_name>.json` (from `generate_aide_integration_stats.py`).
- Samples **fast-p** at **p = 0.0, 1.0, 2.0** for iterations **10, 20, 30, …** through the final iteration (uses cumulative `fast_p_best` by default).

Edit `EVOLVING_RUN_NAMES` and `AIDE_RUN_NAMES` at the top of the script to choose which runs to include.

**Usage:**

```bash
uv run python scripts_integration/new_evolving_agent/analysis/aggregate_fast_p_checkpoints.py
```

Optional flags:

```bash
uv run python scripts_integration/new_evolving_agent/analysis/aggregate_fast_p_checkpoints.py \
  --fast-p-field fast_p_current \
  --stride 10 \
  --output scripts_integration/new_evolving_agent/analysis/aggregated_fast_p_checkpoints.json
```

**Output:**

- `scripts_integration/new_evolving_agent/analysis/aggregated_fast_p_checkpoints.json`

The output maps each run name to checkpoint rows with `fast_p` values at the selected thresholds. Missing stats are reported under `errors` in the JSON.

**Prerequisites:** generate cached stats before running if needed:

```bash
uv run python Self-Evolving-Agent/visualizations/kernelbench/server/generate_run_performance_stats.py --run-name <RUN_NAME>
uv run python Self-Evolving-Agent/visualizations/kernelbench/server/generate_aide_integration_stats.py --layout subset_run --run-name <AIDE_RUN_NAME>
```
